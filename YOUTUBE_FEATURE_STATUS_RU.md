# Примечание к YouTube-функции

YouTube-воспроизведение уже реализовано в исходниках этого архива:
- клиентский Rinku/Chromium adapter;
- HTML-страница с официальным YouTube IFrame Player API;
- сетевые команды назначения источника и управления;
- передача JPEG-кадров на Paper;
- отображение на карте в рамке рядом с телевизором.

Это не означает, что функция прошла игровой тест. Для подтверждения необходимы сборка на Java 25/Gradle и запуск Paper + Fabric клиента с Rinku 3.0.4. Смотри `docs/YOUTUBE.md`.

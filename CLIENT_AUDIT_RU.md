# EtherTV Client 1.2.0-dev — аудит Fabric-клиента

Дата проверки: 18.11.2026

## Найдено и исправлено

1. **Критическая ошибка framing протокола.** Ранее Fabric `StreamCodec` добавлял перед данными дополнительный `int length`, тогда как Paper ожидал, что первые четыре байта сообщения — magic `ETV1`. Из-за этого HELLO и ответы сервера не могли корректно декодироваться. Кодек исправлен: тело custom payload теперь передаётся без второго префикса длины, с `ETV1` в самом начале.
2. **Ошибка конфигурации сборки для Minecraft 26.2.** Старый Loom plugin ID и `loom.officialMojangMappings()` оставались от remapping-сборок. Для Minecraft 26.2 используется новый plugin ID `net.fabricmc.fabric-loom`, без отдельной зависимости mappings. Зависимости Fabric Loader/API переведены на обычные Gradle-конфигурации.
3. **Версия клиента в HELLO** приведена к `1.2.0-dev`.
4. **Несколько записей одним оператором.** Клиентский захват поддерживает одну активную запись. Сервер теперь не переназначает клиентский захват на вторую камеру того же оператора, а использует для неё серверный резервный захват.

## Что подтверждено только статически

- Формат HELLO, FRAME, GAME_AUDIO и управляющих сообщений совпадает с серверным протоколом после исправления framing.
- Ограничения длины payload остаются на клиенте и сервере.
- Согласие на игровое аудио выключено по умолчанию; без установленного `AudioCaptureProvider` игровая дорожка не появится.
- YouTube BrowserSurface adapter `RinkuYoutubeBrowserSurface` присутствует: создаёт Chromium через Rinku, загружает YouTube IFrame Player API и делает JPEG-снимки для передачи на Paper.
- Paper принимает кадры YouTube и выводит их через `MapVideoRenderer` на карту в рамке рядом с телевизором. Это карта-экран 128×128, не прямая GPU-текстура на 3D-модели.

## Что ещё не проверено

- Сборка Fabric-мода на Java 25 и Gradle с указанной версией Loom.
- Совместимость `WorldRenderEvents.END`, GL framebuffer readback и `RegistryFriendlyByteBuf` с фактическими API Fabric/Minecraft 26.2.
- Реальный входящий и исходящий обмен с Paper-сервером.
- Кадровая частота, использование памяти и поведение при потере соединения.
- Реальный запуск Rinku/CEF, загрузка YouTube iframe, отображение кадров и синхронизация звука на реальном клиенте.

## Вывод

Обнаруженная ошибка framing делала мост Paper↔Fabric несовместимым на уровне формата пакета; она исправлена в исходниках. Сборка и работа в Minecraft пока не подтверждены. Этап 2 остаётся условно завершённым до успешной сборки и теста подключения к тестовому Paper-серверу.

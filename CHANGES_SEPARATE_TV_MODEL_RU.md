# Изменения: отдельная модель телевизора ЭТ-1

- Ванильный namespace `assets/minecraft/` полностью исключён из ресурспака.
- ЭТ-1 получает собственную item definition `ethertv:television` и отдельную 3D-модель.
- Серверный плагин создаёт `ItemDisplay` при установке предмета телевизора.
- UUID display-сущности записывается в PDC блока и используется для удаления при разрушении.
- Модель ориентируется экраном к установившему игроку.
- Базовый блок остаётся `JUKEBOX` для интеграции CustomDiscs.
- В Survival разрушение возвращает предмет ЭТ-1 с PDC-меткой; в Creative выпадение отключено.
- Проверены JSON и состав ресурспака. Компиляция и запуск на Paper 26.2 не выполнялись из-за отсутствия JDK 25, Gradle и runtime.
- Добавлен рецепт ЭК-1 для выживания; существующий рецепт ЭТ-1 сохранён.
- Оба рецепта включены по умолчанию и управляются отдельными параметрами config.yml.
- При разрушении ЭК-1 в Survival возвращается предмет камеры с PDC-меткой.

Внешняя клиентская зависимость EtherTV:

rinku_fabric_3.0.4_MC_26.2.jar
- Rinku Fabric 3.0.4 для Minecraft 26.2.
- Нужен на клиенте для Chromium/YouTube.
- Не кладите этот JAR на сервер Paper.
- Для игры поместите его в папку mods вместе с EtherTV Client и Fabric API.
- Лицензия Rinku и лицензии вложенных компонентов находятся внутри JAR.

Для Gradle-сборки клиентского мода эта же зависимость подключается через Modrinth Maven координатами, указанными в client-fabric/build.gradle.

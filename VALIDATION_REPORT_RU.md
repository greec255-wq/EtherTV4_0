# Отчёт проверки EtherTV 1.2.0-dev

## Выполнено

- Проверена структура исходного проекта EtherTV и JAR Rinku 3.0.4.
- По `javap` подтверждены используемые Rinku методы: `initialize`, `isInitialized`, `createBrowser(String, boolean, int, int)`, `loadURL`, `executeJavaScript`, `createScreenshot(boolean)`, `close`.
- Добавлен Rinku adapter через reflection, чтобы базовый клиентский мод не падал при отсутствии Rinku.
- Подключён YouTube IFrame Player API: локальная HTML-страница, запуск/остановка Chromium, Play/Pause/Seek и получение кадров.
- Добавлена loopback-only HTTP-страница для YouTube IFrame Player API.
- Добавлены создание/закрытие браузера, Play/Pause/Seek и синхронизация времени начала.
- Добавлена передача JPEG-кадров от одного выбранного клиента-источника к Paper.
- Сервер проверяет право, мир, координаты телевизора, расстояние, источник кадров, частоту, размер и размер изображения 320×180.
- Добавлен вывод живого потока на карту в рамке через MapVideoRenderer.
- Добавлена смена источника кадров, если текущий игрок уходит или отключается.
- Уточнены версии и координаты Rinku на Modrinth.
- Проверены JSON и YAML конфигурации.
- Новый Rinku adapter прошёл отдельную проверку синтаксиса Java 21 с тестовыми API-заглушками.
- Изменённые Java-файлы прошли проверку на синтаксические ошибки парсером `javac`; ошибки разрешения внешних зависимостей ожидаемы в этой среде.
- Архивы и структура проверяются отдельно перед выдачей.

## Не выполнено / не подтверждено

- Полная сборка Paper JAR и Fabric JAR не выполнена.
- Нет Java 25 и Gradle 9.x в текущей среде.
- Нет запуска Paper 26.2 и Minecraft 26.2 для runtime-проверки.
- Не проверены реальный запуск CEF, звук YouTube, ограничения конкретных видео, задержки и сетевой трафик.
- Прямой GPU-вывод CEF на 3D-модель не сделан: текущая реализация передаёт JPEG-кадры и показывает их через карту-экран в рамке.
- Захват игрового аудио процесса Minecraft через Windows WASAPI, Linux PipeWire и macOS Core Audio не реализован.
- Нагрузочные и межплатформенные испытания не выполнены.

## Итог

Это расширенный комплект исходников с интеграцией YouTube, но пока не готовый проверенный бинарный релиз. Перед использованием нужно собрать оба JAR на Java 25/Gradle 9.x и проверить на отдельном тестовом сервере.

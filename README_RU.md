# Ресурспак EtherTV — телевизор ЭТ-1

Ресурспак добавляет отдельную модель телевизора ЭТ-1 в namespace `ethertv`. Он **не изменяет** модели, текстуры, blockstates или item definitions ванильного `minecraft:jukebox`.

## Как устроено отображение

- Блок `JUKEBOX` остаётся физической основой телевизора, чтобы сохранить совместимость с CustomDiscs.
- При установке помеченного предмета ЭТ-1 плагин создаёт отдельную сущность `ItemDisplay` с item model `ethertv:television`.
- Сущность хранит UUID в PersistentDataContainer блока; при разрушении телевизора она удаляется.
- Модель ориентируется экраном к игроку, который установил телевизор.
- Обычные ванильные проигрыватели остаются со своей исходной текстурой.

## Установка

1. Установи ресурспак на клиенте Minecraft Java или настрой его выдачу сервером.
2. Перезайди на сервер либо перезагрузи ресурспаки.
3. Установи телевизор предметом, выданным EtherTV (`/ether give tv`).

Ресурспак рассчитан на Minecraft Java 26.2 (pack format 88). Для правильного отображения модель и item definition должны находиться в архиве по указанным путям.

## Важно

Ресурспак сам по себе не добавляет телевизор и не меняет поведение блока. Отдельную сущность создаёт серверный плагин EtherTV. Если ресурспак не установлен, телевизор продолжит работать как jukebox, но его 3D-корпус не будет виден.

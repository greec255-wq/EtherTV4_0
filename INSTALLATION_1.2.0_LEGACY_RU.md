# EtherTV 1.2.0-dev — установка, настройка и команды

> **Важный статус:** это полный комплект исходников текущей разработки, а не готовые проверенные JAR-файлы. В среде подготовки нет Java 25 и Gradle 9.x, поэтому собрать и испытать серверный плагин и Fabric-мод здесь не удалось. Не устанавливайте эту dev-версию на основной сервер без отдельной сборки, тестового мира и резервной копии.

## 1. Что входит

- **EtherTV Paper** — телевизор ЭТ-1, камера ЭК-1, запись, архив, карта-экран, сеть громоотводов.
- **EtherTV Client** — Fabric-мод для захвата кадров камеры и клиентского браузера.
- **Rinku 3.0.4** — Chromium-библиотека, нужна клиентам для YouTube.
- **Custom Discs 2.7.0** — пользовательские аудиодиски.
- **Simple Voice Chat 2.6.1 API** — микрофонная дорожка с согласием говорящего.

## 2. Требования

### Сервер

- Minecraft / Paper 26.2, Paper build 135.
- Java 25.
- Custom Discs 2.7.0 и все зависимости, требуемые самим Custom Discs.
- Simple Voice Chat 2.6.1 с API.
- Gradle 9.x для сборки исходников.

### Клиент

- Minecraft 26.2.
- Java 25.
- Fabric Loader 0.19.3 или новее.
- Fabric API 0.158.0+26.2.
- EtherTV Client.
- Rinku Fabric 3.0.4 для Minecraft 26.2 — обязателен именно для YouTube, но не для базового EtherTV.

Rinku 3.0.4 Fabric 26.2 имеет координаты Modrinth `maven.modrinth:bQhBuv7x:LtluKaTp`; они уже прописаны в `client-fabric/build.gradle` как `modRuntimeOnly` для среды разработки. См. страницу версии: https://modrinth.com/mod/rinku/version/3.0.4-26.2-fabric.

## 3. Сборка

В проекте нет Gradle Wrapper. Нужны установленный Gradle 9.x и JDK 25, а также доступ к Maven-репозиториям.

### Серверный JAR

Из корня папки `EtherTV-1.2.0-dev`:

```bash
gradle clean build
```

JAR должен появиться в `build/libs/`. Выбирайте основной JAR, не `-sources` и не `-javadoc`.

### Клиентский JAR

Из папки `client-fabric`:

```bash
gradle build
```

JAR должен появиться в `client-fabric/build/libs/`.

Если Gradle сообщает о несовместимости Java, проверьте `java -version` и `gradle --version`: обе сборки нацелены на Java 25.

## 4. Установка сервера

1. Сделайте резервную копию папок `world`, `plugins` и конфигурации сервера.
2. Установите Paper 26.2 на Java 25 и один раз запустите его.
3. Остановите сервер.
4. Поместите JAR Custom Discs 2.7.0, Simple Voice Chat 2.6.1 и их обязательные зависимости в `plugins/`.
5. Поместите собранный EtherTV JAR в `plugins/`.
6. Запустите сервер и проверьте консоль на ошибки загрузки зависимостей.
7. После первого запуска настройте `plugins/EtherTV/config.yml`.

Не кладите ZIP с исходниками в `plugins/`: Paper загружает JAR.

## 5. Установка на клиент

На каждом компьютере игрока, которому нужны клиентские функции:

1. Установите Fabric Loader для Minecraft 26.2.
2. Поместите Fabric API и собранный `ethertv-client` JAR в папку `mods`.
3. Для YouTube также поместите `rinku_fabric_3.0.4_MC_26.2.jar` в `mods`.
4. Запустите игру через Fabric-профиль.
5. Подключитесь к серверу EtherTV.

Без Rinku базовые серверные функции и клиентский захват изображения камеры могут работать независимо от браузера. YouTube без Rinku не запустится.

## 6. Первый запуск телевизора

1. Выдайте телевизор: `/ether give tv`.
2. Установите ЭТ-1.
3. Получите карту: `/ether screen map`.
4. Получите дополнительные карты командой `/ether screen map`, если нужен большой экран.
5. Поместите карты в смежные рамки, чтобы получился цельный прямоугольник от 1×1 до 4×4. Все рамки должны смотреть в одну сторону и находиться в одной плоскости.
6. Для привязки выполните `/ether screen bind`, `/ether screen bind <канал>` или `/ether screen play <UUID>`. После перестановки рамок повторите привязку.
7. Для внешнего вида корпуса установите `resource-pack/EtherTV-ET1-ResourcePack-26.2.zip`. Ресурспак заменяет модель всех ванильных jukebox, не только блока EtherTV.
8. Для YouTube наведитесь на ЭТ-1 и выполните `/ether youtube <ссылка>`.

YouTube воспроизводится в Chromium на клиенте каждого зрителя. Кадры браузера сжимаются до 320×180 JPEG и передаются серверу; Paper обновляет карту в рамке. Поэтому изображение на карте ограничено её разрешением и частотой обновления. Это не прямая GPU-текстура на 3D-модели телевизора. Корпус ЭТ-1 задаётся отдельным ресурспаком; экранные карты остаются рамками рядом с корпусом.

## 7. Камера и запись

1. Выдайте камеру: `/ether give camera`.
2. Установите ЭК-1.
3. Откройте её правым кликом.
4. Вставьте Custom Disc в первый слот.
5. Если нужна запись микрофона, участник должен включить согласие командой `/ether consent`.
6. Оператор смотрит на камеру и вводит `/ether record start [канал]`.
7. Для остановки наведитесь на камеру и введите `/ether record stop`.

Максимальная длительность по умолчанию — 1800 секунд. Архив сохраняется в `plugins/EtherTV/recordings/<UUID>/`.

## 8. Команды

| Команда | Назначение |
|---|---|
| `/ether give tv` | Выдать телевизор ЭТ-1 |
| `/ether give camera` | Выдать камеру ЭК-1 |
| `/ether screen map` | Получить карту-экран |
| `/ether screen bind` | Подключить ближайшую активную камеру |
| `/ether screen bind <канал>` | Подключить последнюю запись канала |
| `/ether screen play <UUID>` | Запустить архивную запись |
| `/ether record start` | Начать запись с каналом `local` |
| `/ether record start <канал>` | Начать запись с указанным каналом |
| `/ether record stop` | Остановить запись выбранной камеры |
| `/ether recordings` | Показать UUID записей |
| `/ether network add <канал>` | Добавить громоотвод в канал |
| `/ether network remove` | Удалить выбранный сетевой узел |
| `/ether network list` | Показать сетевые узлы |
| `/ether consent` | Включить/отключить согласие на запись микрофона |
| `/ether youtube <ссылка>` | Назначить ролик выбранному телевизору |
| `/ether youtube play` | Воспроизвести |
| `/ether youtube pause` | Пауза |
| `/ether youtube seek <секунды>` | Перейти к позиции |
| `/ether youtube stop` | Остановить YouTube и показать заставку |
| `/ethertv audio-consent` | Переключить согласие на захват игрового аудио на клиенте |

Команды, связанные с телевизором или камерой, выполняются игроком, который смотрит на нужный блок. Нужны права `ethertv.use` или `ethertv.admin`, как указано в `paper-plugin.yml` и обработчиках команд.

## 9. Сеть громоотводов

1. Установите громоотводы на маршруте.
2. Наведитесь на каждый громоотвод и выполните `/ether network add news`.
3. Начните запись с `/ether record start news`.
4. Наведитесь на телевизор и выполните `/ether screen bind news`.

Имя канала: латинские буквы, цифры, `_` и `-`, до 24 символов. Узлы сохраняются в `plugins/EtherTV/network.yml`.

## 10. Что работает только на уровне исходников / что не готово

- **YouTube:** добавлен Rinku-адаптер, локальная HTTP-страница IFrame API, команды Play/Pause/Seek, снимки браузера и серверный поток JPEG на карту. Но компиляция и реальное воспроизведение в Minecraft не проверены.
- **Объединённый экран:** в исходниках добавлено автоматическое обнаружение прямоугольной группы смежных карт 1×1–4×4, общий источник кадров и разрезание кадра на синхронные тайлы. Требуется runtime-проверка на Paper/Minecraft 26.2.
- **Модель ЭТ-1:** добавлен ресурспак с моделью корпуса. В текущем варианте он заменяет модель всех блоков `JUKEBOX`, так как плагин использует этот блок как основу телевизора.
- **Кадры камеры:** клиентский захват framebuffer предусмотрен; реальная работа на MC 26.2 не проверена.
- **Микрофон:** запись Opus через Simple Voice Chat предусмотрена с отдельным согласием игрока; совместимость с конкретным серверным набором не проверена.
- **Игровой звук Minecraft:** провайдеры WASAPI (Windows), PipeWire (Linux) и Core Audio (macOS) не реализованы. Команда `/ethertv audio-consent` сама по себе звук не захватывает; `game-audio.wav` будет пустым.
- **Сборка:** не выполнена в текущей среде из-за отсутствия JDK 25 и Gradle 9.x.
- **Испытания:** не выполнены нагрузочные тесты, проверка синхронизации, проверка разных ОС и тест YouTube-роликов с ограничениями встраивания.

Если ролик запрещён для встраивания, требует авторизации, подтверждения возраста или недоступен в регионе, YouTube-плеер может не воспроизвести его.

## 11. Диагностика

- Если сервер не загружает EtherTV — проверьте Paper 26.2, Java 25, Custom Discs и Simple Voice Chat.
- Если клиент не подключается к серверному мосту — проверьте Fabric API и соответствие версии Minecraft 26.2.
- Если YouTube не появляется — проверьте Rinku 3.0.4, журнал клиента, доступ к сети и наличие карты в рамке рядом с ЭТ-1.
- Если экран не собирается — проверьте, что рамки смежны, образуют прямоугольник, находятся в одной плоскости и смотрят в одну сторону. Если карта чёрная — проверьте, что рядом есть игрок с EtherTV Client и Rinku, а сервер принимает канал `ethertv:bridge`.
- Если нет игрового звука в архиве — это ожидаемое ограничение текущей версии: платформенные аудиопровайдеры ещё отсутствуют.

Перед любым обновлением копируйте `plugins/EtherTV/` и мир сервера.

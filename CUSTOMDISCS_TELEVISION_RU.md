# EtherTV 1.3.0 — управление телевизором через CustomDiscs

## Принцип работы

- CustomDiscs остаётся ответственным за создание пластинки и её аудиовоспроизведение.
- При вставке удалённой YouTube-пластинки в блок ET-1 EtherTV получает `DiscEntry.identifier` из `CustomDiscInsertEvent`.
- Если идентификатор является YouTube URL или 11-символьным ID, EtherTV передаёт его существующему клиентскому Rinku-плееру.
- Клиент делает JPEG-кадры; сервер принимает их через существующий `ethertv:bridge` и обновляет карту-экран через `MapRenderer`.
- При извлечении пластинки EtherTV посылает клиентам команду остановки и выводит заставку NO SIGNAL. Аудио CustomDiscs прекращается самим CustomDiscs.

## Команды

- `/ether play` — продолжить воспроизведение на телевизоре, на который смотрит игрок.
- `/ether pause` — поставить воспроизведение на паузу.
- `/ether screen map` — получить карту-экран.
- `/ether screen bind` — привязать карту-экран к телевизору/источнику согласно существующей логике.
- `/ether record start [канал]` и `/ether record stop` — запись камеры.
- `/ether recordings` — список записей.
- `/ether consent` — согласие на запись микрофона.
- `/ether give tv|camera` — выдача устройств администратором.

Команда `/ether youtube ...` удалена. YouTube-источник назначается вставкой пластинки.

## Требования и ограничения

- На сервере должен быть CustomDiscs 2.7.0 и его штатные зависимости.
- Для изображения нужен EtherTV Client с Rinku у хотя бы одного игрока рядом с телевизором.
- Для звука используется штатный аудиоплеер CustomDiscs/Simple Voice Chat. EtherTV не пытается повторно транслировать ту же аудиодорожку.
- EtherTV передаёт видеоплееру только распознаваемые YouTube URL или ID. Локальные аудиопластинки и другие сервисы не запускают видеорежим.
- YouTube может ограничивать встраивание отдельных роликов, например из-за возрастных, региональных или авторских ограничений.
- Карта имеет низкое разрешение и частоту обновления около 2 кадров/с; это не полноценный HD-плеер.

## Обязательная проверка на тестовом сервере

В текущей среде нет Java 25 и Gradle, поэтому компиляция и runtime-тесты не выполнялись. После сборки проверьте: вставку удалённой YouTube-пластинки, вывод картинки, звук CustomDiscs, `/ether pause`, `/ether play`, извлечение пластинки, обычную аудиопластинку, привязку экрана и запись камеры. Особое внимание — формату `DiscEntry.identifier` для конкретного способа создания пластинки в установленной конфигурации CustomDiscs.

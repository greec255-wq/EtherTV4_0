# Исправления EtherTV 1.2.0-dev

## Исправлено в этом пакете

- Добавлена отсутствовавшая реализация `registerCommand(...)` в `EtherTVPlugin`.
  Ранее `onEnable()` вызывал этот метод, но в исходнике его не было, поэтому
  серверный модуль не мог скомпилироваться.
- Команда `/ether` теперь регистрируется через Paper Lifecycle Command API
  (`LifecycleEvents.COMMANDS` и `BasicCommand`), что соответствует формату
  Paper-плагина с `paper-plugin.yml`.
- Исправлена строка версии в сообщении запуска: `1.2.0-dev`.

## Что осталось проверить

- Полную компиляцию на Java 25 / Gradle 9.x.
- Совместимость Paper API `26.2.build.135-stable` с фактической версией сервера.
- Совместимость CustomDiscs 2.7.0 (его дескриптор заявляет API 1.21.6) с целевым Paper 26.2.
- Работу CustomDiscs, Simple Voice Chat, клиентского Fabric-мода и YouTube на реальном сервере.
- Клиентский Fabric-проект и серверный Paper-проект собираются отдельно.

В среде этой проверки нет Gradle и установлена Java 21, тогда как проект требует
Java 25. Поэтому этот архив содержит исходное исправление, но не является
подтверждённым собранным JAR. Сначала запусти GitHub Actions из инструкции
`GITHUB_ACTIONS_RU.md`; если сборка завершится ошибкой, пришли полный лог.

# YouTube-видео на EtherTV через CustomDiscs

В EtherTV 1.3.0 источник видео назначается не командой, а вставкой удалённой YouTube-пластинки CustomDiscs в телевизор ET-1.

## Поток

1. Создай YouTube-пластинку штатной командой CustomDiscs, держа музыкальную пластинку в руке. CustomDiscs сам сохраняет URL/идентификатор и настраивает аудиовоспроизведение.
2. Вставь готовую пластинку в телевизор ET-1.
3. `CustomDiscTelevisionService` получает событие CustomDiscs и передаёт YouTube-идентификатор существующему EtherTV Client/Rinku-плееру.
4. EtherTV Client открывает ролик и делает JPEG-кадры 320×180 примерно 2 раза в секунду.
5. Сервер принимает кадры через `ethertv:bridge` и обновляет карту-экран через существующий `MapVideoRenderer`.
6. Звук остаётся за CustomDiscs и его интеграцией с Simple Voice Chat/радио; EtherTV не запускает второй аудиоплеер.
7. При извлечении пластинки EtherTV останавливает браузерный источник и сбрасывает экран в NO SIGNAL; CustomDiscs завершает аудио.

## Команды

- `/ether play` — продолжить ролик на телевизоре, на который смотрит игрок.
- `/ether pause` — приостановить ролик.
- `/ether screen map` и `/ether screen bind` — создание и привязка карты-экрана.
- `/ether record start [канал]`, `/ether record stop`, `/ether recordings`, `/ether consent` — функции камер и согласия на запись.

Команды `/ether youtube ...` для назначения URL, перемотки и остановки удалены. Для смены источника вынь текущую пластинку и вставь другую.

## Ограничения

- Для видеокадров нужен EtherTV Client с Rinku у хотя бы одного игрока рядом с телевизором.
- Интеграция принимает YouTube URL или 11-символьный ID из `DiscEntry.identifier`. Если конкретная сборка/настройка CustomDiscs возвращает другой формат, видеосвязку потребуется адаптировать после проверки значения.
- Встраивание может быть запрещено самим YouTube для отдельных роликов.
- Карта имеет ограниченное разрешение и частоту обновления; это не HD-воспроизведение.
- Сборка Java 25 и игровые runtime-тесты в этой среде не выполнялись.

# EtherTV 1.2.0-dev — отдельная модель телевизора ЭТ-1

## Главное изменение

ЭТ-1 больше не требует подмены модели ванильного `minecraft:jukebox`. Обычные проигрыватели сохраняют штатный внешний вид. Для отмеченного плагином телевизора при установке создаётся отдельная сущность `ItemDisplay`, использующая модель `ethertv:television` из ресурспака.

## Состав архива

- `src/` — серверный исходный код EtherTV.
- `client-fabric/` — клиентская часть EtherTV.
- `resource-pack/EtherTV-ET1-ResourcePack-26.2.zip` — готовый ресурспак.
- `resource-pack/assets/ethertv/` — исходные item definition, модель и текстуры телевизора.
- `libs/CustomDiscs-2.7.0.jar` — зависимость, ранее включённая в проект.

## Установка

1. Собери серверный плагин в среде с JDK 25 и Gradle 9.x.
2. Установи EtherTV и требуемые зависимости на тестовый Paper 26.2 сервер.
3. Установи `resource-pack/EtherTV-ET1-ResourcePack-26.2.zip` как ресурспак клиента или настрой выдачу сервером.
4. Получи телевизор через `/ether give tv` и поставь его. Корпус создаётся отдельной display-сущностью, а базовый jukebox остаётся для CustomDiscs.

## Важные проверки

- Ресурспак не содержит `assets/minecraft/` и не меняет ванильные jukebox-модели.
- UUID display-сущности сохраняется в PDC блока; при разрушении телевизора сущность удаляется.
- В режиме выживания при разрушении возвращается помеченный предмет ЭТ-1; в творческом режиме предмет не выпадает.
- Модель ориентируется экраном к установившему игроку.

## Статус тестирования

Проверены структура исходного ZIP, JSON ресурспака и отсутствие overrides ванильного namespace. Полная компиляция и запуск не выполнены: доступна Java 21, проект требует Java 25; Gradle и Paper runtime в среде подготовки отсутствуют. Перед основным сервером обязательно проверь на тестовом сервере совместимость Paper 26.2, видимость ItemDisplay и ориентацию модели.

## Рецепты выживания

Оба рецепта включены по умолчанию и создают предметы с внутренними метками EtherTV:

### Телевизор ЭТ-1

```text
[ ][J][ ]
[C][R][R]
[I][L][I]
```

- J — проигрыватель (Jukebox)
- C — медный блок
- R — редстоун
- I — железный слиток
- L — громоотвод

### Камера ЭК-1

```text
[ ][I][ ]
[R][D][S]
[ ][C][ ]
```

- I — железный слиток
- R — редстоун
- D — раздатчик (Dispenser)
- S — подзорная труба
- C — медный слиток

Рецепты доступны обычным игрокам без административных прав. Команды `/ether give tv` и `/ether give camera` остаются административными. При разрушении камеры в режиме выживания возвращается помеченный предмет ЭК-1, чтобы его можно было перенести и установить снова.

Настройки: `television.recipe-enabled` и `camera.recipe-enabled` в `config.yml`.

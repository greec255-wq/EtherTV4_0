# EtherTV 1.3.0-dev

Исходный проект обновлён из EtherTV 1.2.0-dev. Это **development-сборка**: она предназначена для тестового сервера, не является подтверждённым релизом. Готовый JAR не приложен, поскольку компиляция в среде создания архива не выполнялась.

## Что изменено в этой версии

- Добавлено постоянное состояние телевизора в PDC блока: канал `1–15`, режим `TRANSMITTER/RECEIVER`, UUID телевизора.
- Shift + ПКМ по корпусу ЭТ-1 циклически меняет канал `1 → … → 15 → 1`.
- `/ether mode` переключает передатчик/приёмник. Приёмник и передатчик теперь представлены отдельным состоянием блока.
- `/ether status` показывает канал, режим, число громоотводов непосредственно сверху и расчётный радиус.
- Радиус вычисляется по вертикальному непрерывному столбу громоотводов прямо над блоком: `min(число × 1000, 20000)`. Расстояние — полное 3D, в пределах одного мира. Промежуточные чанки не загружаются.
- Удалена старая логика графа ретрансляторов. Старые `/ether network add/remove` оставлены как совместимые команды-заглушки и не строят сеть.
- Добавлена отдельная 3D item-модель камеры ЭК-1 для ресурспака: металлический корпус, синеватый объектив и красный индикатор.
- Рендерер карты теперь рисует чёрный экран, если кадр отсутствует, вместо сохранения старого изображения.
- Версия проекта и Paper plugin metadata обновлены до `1.3.0-dev`.

## Честная матрица готовности

| Механика | Состояние в этом архиве |
|---|---|
| Ровно 15 каналов и циклическое переключение Shift+ПКМ | Реализовано для блока ЭТ-1 |
| Сохранение канала/режима/UUID блока | Реализовано через PDC блока |
| Отдельное переключение режима | Реализовано командой `/ether mode`; интерактивная нижняя точка корпуса ещё не реализована |
| Формула прямого радиуса по громоотводам сверху | Реализована в контроллере; автоматическая диспетчеризация потоков приёмникам ещё не подключена |
| Ближайший передатчик и стабильный UUID tie-break | Реализован метод выбора в контроллере, но не включён в рабочий цикл доставки видео |
| Один общий VideoStream для всех приёмников | Не завершено; текущая система экранов использует существующий общий PlaybackFeed внутри одной группы карт |
| Строго фиксированная экранная позиция на передней стороне ТВ | Не завершено; используется прежняя привязка к рамкам рядом с ТВ |
| Очистка карты при отсутствии кадра | Реализована отрисовка чёрного кадра при отсутствии данных; автоматическая очистка при всех событиях удаления/потери связи требует интеграции |
| ЭК-1 как отдельная 3D-модель в руке | Добавлена item-модель в ресурспак; размещённая камера пока остаётся блоком-раздатчиком |
| Уникальный ID/автор/владелец записи на пластинке | Частично: UUID каталога записи и оператор сохраняются; полноценная персистентная привязка метаданных к каждой Custom Disc не завершена |
| Передача аудио через SVC на локальные точки приёмников | Не завершено. Есть захват микрофона в WAV, но нет общей аудиошины воспроизведения у приёмников |
| Согласие/уведомление о микрофонной записи | Имеется в базовой реализации 1.2.0-dev |
| Запись любых звуков клиента (окружение Minecraft) | Не реализована: клиентский AudioCaptureProvider отсутствует |
| YouTube | Существующая клиентская интеграция оставлена как экспериментальная. Она не гарантирует вывод синхронного видео/звука на карту и не обходит ограничения встраивания |
| Локальные записи | Существующий архив кадров и микрофонной WAV-дорожки сохранён |
| Восстановление полной трансляции после рестарта | Не завершено; PDC сохраняет состояние телевизора, но активный поток и привязка карты автоматически не восстанавливаются |

## Установка для тестирования

1. Сделай резервную копию мира и папки `plugins`.
2. Используй совместимую сборку Paper для Minecraft 26.2 и Java 25.
3. Установи CustomDiscs 2.7.0, Simple Voice Chat и необходимые им зависимости.
4. Собери серверный модуль из корня проекта: `gradle build`.
5. JAR появится в `build/libs/`. Помести его в `plugins/` и запусти тестовый сервер.
6. Установи ресурспак из `resource-pack/EtherTV-ET1-ResourcePack-26.2.zip`.
7. Выдай телевизор: `/ether give tv`.
8. Установи один или несколько громоотводов непосредственно вертикально над телевизором-передатчиком. Каждый добавляет 1000 блоков дальности, максимум 20000.
9. Shift + ПКМ по телевизору меняет канал. `/ether mode` переключает режим. `/ether status` показывает состояние.

## Команды

- `/ether give tv`
- `/ether give camera`
- `/ether mode` — переключить режим целевого телевизора
- `/ether status` — состояние целевого телевизора
- `/ether screen map`, `/ether screen bind`, `/ether screen play <UUID>` — существующие функции экранов/архива
- `/ether record start [канал]`, `/ether record stop`, `/ether recordings`
- `/ether consent` — согласие на запись микрофона
- `/ether youtube ...` — экспериментальная клиентская функция

## Сборка

Серверный модуль требует Java 25 и Gradle. В исходном проекте нет Gradle Wrapper. Клиентский модуль Fabric собирается отдельно из `client-fabric/`. В этой поставке сборка и runtime-тесты не подтверждены. Никакой JAR EtherTV 1.3.0-dev не заявляется как готовый.

## Важное

Этот архив содержит существенные изменения 1.3.0-dev, но **не реализует всю согласованную спецификацию**. В частности, автоматическое соединение передатчиков с приёмниками, общая синхронизация видео/аудио, физическая интерактивная точка, строгая геометрия экрана, полноценная камера в мире и завершённое восстановление потоков требуют дальнейшей разработки. Эти ограничения перечислены явно, чтобы тестирование не основывалось на ложных ожиданиях.


## Интеграция CustomDiscs

См. `docs/CUSTOMDISCS_TELEVISION_RU.md`: YouTube-пластинка запускает существующий видеопоток ET-1; команды управления — `/ether play` и `/ether pause`. Команды `/ether youtube ...` удалены.

# Сборка EtherTV через GitHub Actions (без установки Java и Gradle на телефон)

В репозитории уже добавлены два workflow:

- `.github/workflows/build-server.yml` — собирает серверный Paper-плагин.
- `.github/workflows/build-client.yml` — собирает клиентский Fabric-мод.

Оба workflow используют Java 25 и Gradle 9.2.1. Это конфигурация автоматической сборки, а не подтверждение успешной компиляции: реальный результат появится только после запуска workflow на GitHub.

## 1. Создай репозиторий GitHub

1. Открой https://github.com и войди в свой аккаунт.
2. Нажми **New repository**.
3. Назови репозиторий `EtherTV`.
4. Для приватного проекта выбери **Private**. Не публикуй в репозитории пароли, токены, адреса серверных панелей или другие секреты.
5. Нажми **Create repository**.

## 2. Загрузи исходники

1. Распакуй `EtherTV-1.2.0-dev-source-package.zip` на устройстве.
2. Открой созданный репозиторий на GitHub.
3. Выбери **Add file → Upload files**.
4. Загрузи содержимое папки `EtherTV-1.2.0-dev`, а не сам ZIP-файл. В корне репозитория должны быть видны `build.gradle.kts`, `settings.gradle.kts`, `src`, `client-fabric`, `libs`, `external-dependencies`, `docs` и `.github`.
5. Внизу нажми **Commit changes**.

Если мобильный сайт не позволяет удобно загрузить папку `.github`, проверь после загрузки, что оба файла workflow присутствуют в `.github/workflows/`. Без них GitHub не покажет соответствующие процессы сборки.

## 3. Запусти сборку Paper-плагина

1. В репозитории открой вкладку **Actions**.
2. В левом списке выбери **Build EtherTV Paper plugin**.
3. Нажми **Run workflow → Run workflow**.
4. Открой появившийся запуск и дождись завершения.
5. Если статус зелёный (**Success**), прокрути страницу запуска вниз до **Artifacts**.
6. Скачай `EtherTV-Paper-JAR`. Внутри будет собранный серверный JAR.

Именно этот серверный JAR предназначен для папки `plugins` на Paper. Не загружай архив с исходниками в `plugins`.

## 4. (Отдельно) Собери клиентский Fabric-мод

1. В **Actions** выбери **Build EtherTV Fabric client mod**.
2. Нажми **Run workflow → Run workflow**.
3. После статуса **Success** скачай artifact `EtherTV-Fabric-Client-JAR`.
4. Это клиентский мод для папки `mods` на клиенте Minecraft с Fabric, а не для серверной папки `plugins`.

## 5. Если сборка завершилась ошибкой

1. Открой неудачный запуск во вкладке **Actions**.
2. Открой шаг с красным крестиком и скопируй полный текст ошибки.
3. Пришли сюда текст ошибки или скриншот. По нему можно определить, что нужно исправить.

Не пытайся переименовать исходный ZIP в `.jar`: это не компиляция.

## Важные ограничения текущего dev-пакета

- Успешная сборка ещё не доказывает, что плагин работает на реальном Paper-сервере. Нужен отдельный игровой тест.
- Серверный проект объявляет Paper API `26.2.build.135-stable` и Java 25. Убедись, что версия Paper на хостинге совместима с этим API и сервер запускается на подходящей Java.
- В пакете есть `CustomDiscs-2.7.0.jar` как compile-time библиотека. Это не означает, что зависимость уже установлена на сервере.
- Для работы интеграции голосового чата потребуется установленный Simple Voice Chat.
- Клиентский Fabric-мод и Rinku нужны на клиентской стороне для браузерной части YouTube.
- В текущей dev-версии ещё не реализованы системные провайдеры захвата звука игры для Windows/Linux/macOS; переключатель согласия сам по себе не добавляет такой захват.
- YouTube-видео может не воспроизводиться, если владелец запретил встраивание или сервис требует вход/проверку возраста/региона.

## Что отправить для проверки

После сборки пришли:

- статус обоих workflow (Success или Failed);
- если Failed — полный лог ошибки;
- версию Paper и Java, выбранную в панели Play Hosting.

Не присылай пароли, токены GitHub или данные доступа к хостингу.
